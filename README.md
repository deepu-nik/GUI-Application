# DAA Mini Projects — Java Swing

Two small GUI-based mini-projects demonstrating Design and Analysis of Algorithms (DAA) strategies. Built in plain Java with Swing; no third-party libraries or build tools are required.

## Projects
- **MessMate:** College mess meal-slot scheduler using Maximum Bipartite Matching (Graph Algorithms).
- **TripWise:** Tourist attraction planner using Two-Constraint 0/1 Knapsack (Dynamic Programming).

## Requirements
JDK 8 or later.

## Run
See the README inside each project folder for compile and run commands.

## Academic scope
These are educational mini-project implementations with explicit model assumptions and complexity analysis. They are not production scheduling or travel-planning systems.
